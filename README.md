# T.M.2.K

Website for **T.M.2.K (Thatman2Know)**, Cam Carver, a St. Louis bass and dubstep DJ.

One self-contained page: mixes with SoundCloud players, past shows, bio and booking.

## Hosting

Served by GitHub Pages from the `main` branch root. No build step.

## Editing

Everything lives in `index.html`:

- **Mixes**: the `MIXES` array in the script at the bottom (SoundCloud track id, title, date, plays, blurb).
- **Shows**: the `<ol class="shows">` list.
- **Colors**: the tokens in `:root` at the top of the `<style>` block (jersey black, pink, neon blue, violet).
